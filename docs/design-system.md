# Design System

## Visual Direction
- Base background: near-black with subtle tonal gradients
- Accent usage: one bright accent per theme, applied sparingly
- Geometry: rounded blocks and pill controls
- Depth: soft glow and restrained shadows, no faux-3D bevels
- Typography: bold, geometric-feeling hierarchy with quiet supporting labels

## Themes
### Obsidian Sky
- Base: charcoal to ink black
- Accent: cool sky blue
- Mood: calm, premium, default launch theme

### Iris Pulse
- Base: graphite with violet undertones
- Accent: iris purple
- Unlock: best score 25

### Verdant Glow
- Base: deep evergreen-black
- Accent: mint-green glow
- Unlock: best score 60

## Layout Rules
- Tower stays centered and visually dominant
- Score sits at top center during play
- Combo state uses one compact chip, never a large banner
- Results screen prioritizes replay over secondary actions

## Components
- Pill primary button
- Soft-outline secondary button
- Compact stat card
- Theme chip
- Daily challenge capsule
- Minimal settings row
