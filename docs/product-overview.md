# Product Overview

Perfect Stack is a minimalist score-chasing stacking game built for short, premium-feeling mobile sessions. The core loop is one tap: drop a moving block, maintain the tower, and chase perfect placements that feel materially better than normal ones.

## Product Thesis
- Win through polish, not complexity
- Make the first run legible within one second
- Reserve the strongest feedback for perfects, streaks, and new-best moments
- Keep the replay loop nearly instantaneous

## Core Screens
- Home: play-first landing screen with best score, themes, challenge entry, and settings
- Gameplay: minimal HUD over a tower-first scene
- Results: score, best, streak, replay, and share

## MVP Surface
- Endless mode
- Three launch-ready themes
- Persistent best score and settings
- Daily challenge entry point with lightweight challenge logic
- Shareable results card
- Analytics abstraction ready for swap-in
