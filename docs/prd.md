# PRD

## Goal
Deliver a premium dark minimalist iOS MVP that proves the game feel of Perfect Stack and sets up launch-quality assets, instrumentation, and future monetization paths.

## User Promise
- Instant comprehension
- Clean sensory rewards
- Fast retries
- Visible mastery through perfect streaks and best scores

## Must-Haves
- Playable home, game, and results loop
- Block slicing and fail state
- Distinct perfect-hit mechanics and feedback
- Best score persistence
- Perfect streak tracking
- Three themes with unlock progression
- Share card flow
- Daily challenge entry and functional challenge logic
- Reduced motion, mute, and haptics toggles
- Analytics event wiring
- StoreKit-ready but disabled monetization abstraction

## Non-Goals
- Account systems
- Heavy progression economies
- Forced ads
- Auth, push notifications, or multiplayer
- Stripe checkout inside the iOS app

## Primary Metrics
- Install to first-play conversion
- Runs per first session
- Perfect lands per run
- D1 retention
- Share tap rate
- Crash-free sessions
